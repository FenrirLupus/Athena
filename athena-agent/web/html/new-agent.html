Set up an agent

Four steps: who it is, where it answers from, the key it uses, and which model.

Who is this agent?

The name is its address: lowercase, no spaces.

Where does it answer from?

A remote endpoint speaks one of two wire formats; a local model is served from ~/.athena/models.

Credentials

The key is written to ~/.athena/.secret as agent-<name>=… and never into the profile — a profile gets copied and archived; a secret file does not.

A local model needs no key — it is served on this machine.

Which model?

The window is what the whole prompt stack is sized against.
